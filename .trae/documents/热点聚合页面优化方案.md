# 热点聚合页面布局与功能优化方案

## Context

当前热点聚合页面（`Hotpoint.tsx`）存在以下问题：
1. **布局嵌套两层 Tab**（国内/国外 → 平台），切换繁琐，用户体验差
2. **缺少跨平台"综合热搜榜"**，无法一眼看到全网最热内容
3. **搜索仅限当前平台**，无法全局搜索
4. **平台列表用 Tab 展示不够直观**，看不到各平台热点数量对比
5. **缺少更新时间显示**，用户不知道数据新鲜度
6. **热点列表项样式单一**，前3名没有特殊样式，热度值未格式化
7. **缺少复制链接等便捷操作**

后端 API 已支持所有必要数据（`/hotpoint/list` 返回全部平台数据），无需修改后端。

## 优化方案

### 1. 顶部统计栏增强
- 4 个统计卡片：国内平台数、国外平台数、热点总数、最后更新时间
- 每个卡片带图标和主题色
- 搜索框改为全局搜索（跨所有平台）
- 保留"刷新缓存"和"强制采集"按钮

### 2. 三级 Tab 结构优化为一级 Tab
新 Tab 结构：
- **🔥 综合热搜榜**（新增）：跨平台聚合 Top 50 热点，按热度排序
- **🏠 国内热点**：左侧平台卡片菜单 + 右侧热点列表
- **🌍 国外热点**：同上结构

### 3. 综合热搜榜视图（新增功能）
- 聚合所有平台的热点，按热度值降序排序
- 显示 Top 50 热点
- 每条显示：排名（前3名金银铜奖章样式）、标题、热度值（格式化为万/亿）、来源平台标签、复制链接按钮
- 支持全局搜索过滤

### 4. 平台热点视图优化
- **左侧平台菜单**：卡片式列表，每项显示平台颜色圆点、名称、热点数量
- **右侧热点列表**：带排名圆圈（前3名特殊颜色）、标题、热度、作者标签、打开链接
- 搜索框在顶部全局生效

### 5. 热点列表项增强
- 排名前3名：金(#FFD700)、银(#C0C0C0)、铜(#CD7F32) 圆形奖章样式
- 热度值格式化：> 10000 显示为 "1.2万"，> 100000000 显示为 "1.2亿"
- 复制链接按钮（使用 navigator.clipboard）
- 所有文本遵循 `word-break: break-all; overflow-wrap: anywhere`（用户偏好）
- 长标题自动换行，不出现横向滚动条

### 6. 其他优化
- 最后更新时间：前端记录每次成功获取数据的时间
- 空状态优化：无数据时显示引导提示
- 加载状态：骨架屏替代 Spin

## 修改文件

仅修改 1 个文件：
- **`webui-new/src/pages/Hotpoint.tsx`**：重写页面布局和功能

不需要修改后端、API 层或创建新文件。所有数据已通过 `getHotpointList()` 返回，前端聚合排序即可。

## 实现步骤

1. 在 `Hotpoint.tsx` 中新增辅助函数：
   - `formatHotValue(hot: string)`: 格式化热度值（万/亿）
   - `getRankStyle(rank: number)`: 返回排名样式（前3名特殊颜色）
   - `aggregateAllItems(data)`: 聚合所有平台热点并按热度排序

2. 重写顶部统计栏：4 个带图标的统计卡片 + 全局搜索 + 操作按钮

3. 重写 Tab 结构：
   - 综合热搜榜 Tab：聚合列表，每条带平台标签和复制按钮
   - 国内/国外 Tab：左侧平台菜单 + 右侧热点列表

4. 优化热点列表项渲染：排名样式、热度格式化、复制链接

5. 添加更新时间状态（前端记录）

## 验证

2. 前端构建成功：`npm run build`
3. 部署到 `api/webui` 并重启服务
4. 访问热点聚合页面验证：
   - 综合热搜榜显示跨平台 Top 热点
   - 国内/国外平台切换正常
   - 全局搜索跨平台生效
   - 热度值格式化正确
   - 复制链接功能正常
   - 长文本自动换行，无横向滚动条
