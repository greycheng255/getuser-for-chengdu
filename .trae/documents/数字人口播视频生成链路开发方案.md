# 数字人口播视频生成链路 — 开发方案

## Context

当前系统在"热点→视频生成→发布→互动"主链路上领先竞品，但飞书文档中两个竞品（超级IP智能体、知了矩阵系统）具备的核心能力——**数字人口播视频生成**（声音克隆+数字人+自动字幕/BGM/封面）和**对标文案提取仿写**——我们完全缺失。本方案补齐 P0 阶段的口播视频全链路，对标超级IP智能体的九大核心能力。

## 实施步骤

### Step 1: 对标文案提取服务（不依赖外部 API）

**新建** `api/services/ai/script_extractor.py`

流程：输入视频链接 → yt-dlp 下载 → FFmpeg 提取音频 → faster-whisper 识别 → 清洗输出文案

```python
class ScriptExtractor:
    async def extract(self, video_url: str, platform: str = "") -> dict:
        # 1. yt-dlp CLI 下载视频到 /tmp/
        # 2. FFmpeg 提取 wav 音频 (16kHz mono, whisper 要求)
        # 3. faster-whisper 识别 (model_size="base", language="zh")
        # 4. 清洗：去掉语气词、合并断句、分段
        # 5. 返回 {raw_text, cleaned_text, segments, duration, video_url}
```

关键实现：
- yt-dlp 用 `subprocess.run(["yt-dlp", ...])` 调 CLI（比 import 更可靠，venv 中无 yt_dlp 模块）
- FFmpeg：`ffmpeg -i video.mp4 -ar 16000 -ac 1 -c:a pcm_s16le audio.wav`
- faster-whisper：`WhisperModel("base", device="cpu", compute_type="int8")`，首次运行自动下载模型
- 支持 X/抖音/小红书/B站等平台链接（yt-dlp 原生支持）

## 实施优先级

全部一起做。Phase 3（声音克隆+数字人）采用**降级策略**：无 API Key 时自动降级为本地 TTS（通义千问 TTS）+ 图片视频（静态形象照+音频合成），配好 API Key 后自动切换为真实 CosyVoice/HeyGem 服务。

| 阶段 | 内容 | 依赖 | 降级方案 |
|---|---|---|---|
| **Phase 1** | Step 1-2（文案提取+仿写） | faster-whisper 安装 | 无需降级 |
| **Phase 2** | Step 5（字幕/BGM/封面） | 无 | 无需降级 |
| **Phase 3** | Step 3-4（声音克隆+数字人） | DASHSCOPE_API_KEY + HEYGEM_API_URL | 无Key→本地TTS+图片视频 |
| **Phase 4** | Step 6-9（全链路+前端） | Phase 1-3 完成 | 全链路降级模式 |

**降级模式具体实现**：
- 声音克隆无 Key：跳过克隆步骤，直接用通义千问 TTS（QIANWEN_API_KEY 已配置）或 edge-tts（免费）合成音频
- 数字人无 Key：用 FFmpeg 将形象照+音频合成为图片视频（静态画面+口播音频+字幕），不生成唇形同步
- 配好 DASHSCOPE_API_KEY 后：自动切换 CosyVoice 真实声音克隆
- 配好 HEYGEM_API_URL 后：自动切换 HeyGem 真实数字人口播

## 验证方式

1. **文案提取**：输入一个 X/抖音视频链接 → 验证返回的文案与视频口播内容一致
2. **文案仿写**：输入一段文案 → 验证改写后语义保留但用词不同
3. **声音克隆**：上传录音 → 验证合成音频与原声线相似
4. **数字人**：上传形象照+音频 → 验证生成的视频唇形同步
5. **全链路**：输入对标视频链接 → 一键生成 → 验证输出包含视频+字幕+封面+文案
6. **E2E 测试**：在 `/tmp/e2e_business_flow.py` 新增口播视频链路测试项
