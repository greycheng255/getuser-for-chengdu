- **后端**: Python 3 + FastAPI + SQLAlchemy (async) + PostgreSQL + Playwright

## 二、分阶段开发计划

### 第一阶段：多平台发布能力扩展（P0 核心）

**目标**: 将发布能力从 X 单平台扩展到国内主流平台

#### 1.1 发布服务抽象层

- [ ] 创建 `api/services/publisher/` 目录，抽象统一发布接口
- [ ] 定义 `BasePublisher` 抽象基类：`publish(content, video_url, cookies) → PublishResult`
- [ ] 将现有 X 平台发布逻辑重构为 `XPublisher(BasePublisher)`
- [ ] 创建 `PublisherFactory`：根据平台名返回对应 Publisher 实例

#### 1.2 抖音发布器

- [ ] 创建 `DouyinPublisher`：Playwright 自动化上传视频 + 发布
- [ ] 支持视频上传（抖音创作者中心）
- [ ] 支持标题/文案/话题标签输入
- [ ] 发布后提取视频链接

#### 1.3 小红书发布器

- [ ] 创建 `XhsPublisher`：Playwright 自动化发布图文/视频笔记
- [ ] 支持视频上传 + 封面选择
- [ ] 支持标题/正文/话题标签

#### 1.4 视频号/B站/微博/快手发布器

- [ ] `WeixinVideoPublisher`：微信视频号发布
- [ ] `BiliPublisher`：B站投稿
- [ ] `WeiboPublisher`：微博视频发布
- [ ] `KuaishouPublisher`：快手发布

#### 1.5 多平台发布编排

- [ ] 创建 `MultiPlatformPublisher` 服务：接收内容 + 目标平台列表，并行/串行分发
- [ ] 数据库模型：`PublishTask`（统一发布任务表，记录各平台发布状态）
- [ ] API 路由：`POST /api/publish/multi-platform`
- [ ] 前端：发布配置面板（选择目标平台、差异化文案编辑）

**预计工期**: 3-4 周

### 数据库新增模型

```python
# 统一发布任务表（替代当前 X 专用表）
class PublishTask(Base):
    id: int
    task_id: str          # UUID
    source_post_id: str   # 来源热点帖子 ID
    platform: str         # x/douyin/xhs/weibo/bili/kuaishou
    account_id: str       # 发布账号标识
    content: str          # 发布文案
    video_url: str        # 视频URL
    status: str           # pending/publishing/published/failed
    published_url: str    # 发布后的链接
    scheduled_at: int     # 定时发布时间
    published_at: int     # 实际发布时间
    retry_count: int      # 重试次数
    error_msg: str

# 每日统计汇总表
class DailyStats(Base):
    id: int
    date: str             # YYYY-MM-DD
    platform: str
    hotpoint_count: int   # 热点抓取量
    video_count: int      # 视频生成量
    publish_count: int    # 发布量
    publish_success: int  # 发布成功量
    comment_count: int    # 互动量
    like_count: int       # 点赞量
    reply_count: int      # 回复量
```

## 五、关键风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 各平台反爬升级 | 发布/互动失败率升高 | Cookie 池轮换 + Playwright 指纹规避 + 人工验证码降级 |
| 视频生成 API 限额 | 批量生成受限 | 队列排队 + 多 API Key 轮换 + 降级纯文字发布 |
| 多平台 Playwright 并发资源 | 服务器内存/CPU 压力 | 浏览器实例池 + 单实例复用 + 超时熔断 |
| 平台规则差异大 | 适配成本高 | 抽象基类统一接口 + 各平台独立实现 + 差异化配置 |
| 账号批量封禁 | 矩阵失效 | 账号分组管理 + 频次控制 + 异常熔断 + IP 代理池 |
