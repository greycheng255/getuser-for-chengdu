### 1.2 功能重叠详细分析

#### 重叠点1：话术库 vs 互动话术配置（高度重叠 · P0）

| 维度 | 内容运营-话术库 | 账号互动-互动话术 | 重叠分析 |
|------|----------------|------------------|----------|
| 功能定位 | 通用话术模板库（评论/私信/发布文案） | 互动专用话术（评论/回复） | **高度重叠** |
| 使用场景 | 自动化流水线、发布中心 | 互动监控、机器人账号 | 部分重叠 |
| 数据模型 | script_library表（type: comment/dm/publish） | interaction_config表（comment_templates） | **数据冗余** |
| 管理入口 | /script-library | /interaction-config | **重复入口** |
| **建议方案** | **合并为统一话术库**，按type区分用途 | 互动模块引用话术库API | 消除重叠 |

#### 重叠点2：机器人账号 vs 发布账号（高度重叠 · P0）

| 维度 | 内容运营-发布账号 | 账号互动-机器人账号 | 重叠分析 |
|------|------------------|------------------|----------|
| 功能定位 | 内容发布账号管理 | 互动操作账号管理 | **高度重叠** |
| 账号类型 | publisher_account表 | bot_account表 | **数据冗余** |
| Cookie管理 | Cookie池轮换 | Cookie池轮换 | **逻辑重复** |
| 账号健康度 | 发布成功率统计 | 互动成功率统计 | 可统一 |
| **建议方案** | **合并为统一账号管理**，按role区分（publisher/interactor/both） | 复用账号服务 | 消除重叠 |

#### 重叠点3：发布调度 vs 互动调度（部分重叠 · P1）

## 四、统一账号管理模块详细设计

> **优先级**: P0（消除功能重叠核心模块）  
> **预计工期**: 3天（Day 1-2）  
> **负责人**: 开发者A

### 4.1 设计目标

消除现有系统中"发布账号"和"机器人账号"的功能重叠，建立统一的账号管理体系：

1. **单一数据源**：合并 `publisher_accounts` 和 `bot_accounts` 为统一的 `unified_accounts` 表
2. **角色分离**：通过 `role` 字段区分账号用途（publisher/interactor/both）
3. **能力复用**：Cookie池轮换、健康度评分、分组管理等逻辑统一实现
4. **向后兼容**：提供兼容层，现有代码无需大规模重构

### 4.2 数据模型（unified_accounts 表）

```sql
CREATE TABLE unified_accounts (
    -- 主键
    id SERIAL PRIMARY KEY,
    account_id VARCHAR(64) UNIQUE NOT NULL,           -- 账号唯一标识

    -- 基础信息
    user_id INTEGER NOT NULL DEFAULT 1,                -- 归属用户ID（数据隔离）
    owner_user_id INTEGER,                              -- 归属用户ID（兼容旧字段）
    platform VARCHAR(32) NOT NULL,                     -- 平台代号（dy/xhs/ks/bili/wb/x_twitter）
    account_name VARCHAR(128) NOT NULL,                -- 账号名称

    -- 角色与用途
    role VARCHAR(32) NOT NULL DEFAULT 'both',          -- publisher / interactor / both
    capabilities TEXT,                                  -- 能力标签 JSON（如["publish","comment","like"]）

    -- Cookie管理
    cookies TEXT NOT NULL,
    cookie_expires_at TIMESTAMP,
    cookie_refresh_enabled BOOLEAN DEFAULT FALSE,

    -- 状态管理
    status VARCHAR(32) NOT NULL DEFAULT 'active',      -- active/expired/invalid/needs_relogin/cooldown/disabled
    is_active BOOLEAN NOT NULL DEFAULT TRUE,
    health_score FLOAT DEFAULT 100.0,                  -- 健康度评分（0-100）

    -- 配额管理
    daily_limit INTEGER NOT NULL DEFAULT 5,
    today_count INTEGER NOT NULL DEFAULT 0,
    today_date VARCHAR(10) NOT NULL DEFAULT '',

    -- 成功/失败统计
    successes INTEGER NOT NULL DEFAULT 0,              -- 连续成功
    failures INTEGER NOT NULL DEFAULT 0,               -- 连续失败
    total_successes INTEGER NOT NULL DEFAULT 0,
    total_failures INTEGER NOT NULL DEFAULT 0,

    -- 冷却管理
    cooldown_until INTEGER NOT NULL DEFAULT 0,
    cooldown_reason VARCHAR(128),

    -- 时间戳
    last_login_time TIMESTAMP,
    last_used_ts INTEGER NOT NULL DEFAULT 0,
    last_publish_time TIMESTAMP,                       -- role=publisher/both
    last_interact_time TIMESTAMP,                      -- role=interactor/both
    created_at TIMESTAMP NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMP NOT NULL DEFAULT NOW(),

    -- 分组管理
    account_group VARCHAR(64) DEFAULT '',              -- domestic_new/overseas_us 等
    region VARCHAR(32) DEFAULT '',                     -- cn/us/eu/sea 等

    -- 扩展
    label VARCHAR(128),
    extra TEXT,                                         -- JSON

    -- 约束
    CONSTRAINT uq_unified_accounts_user_platform_name
        UNIQUE (user_id, platform, account_name)
);

-- 索引
CREATE INDEX idx_ua_platform_status ON unified_accounts(platform, status);
CREATE INDEX idx_ua_role ON unified_accounts(role);
CREATE INDEX idx_ua_group ON unified_accounts(account_group);
CREATE INDEX idx_ua_owner ON unified_accounts(owner_user_id);
CREATE INDEX idx_ua_health ON unified_accounts(health_score);
```

### 4.3 角色与状态定义

```python
class AccountRole(str, Enum):
    PUBLISHER = "publisher"      # 仅用于内容发布
    INTERACTOR = "interactor"    # 仅用于用户互动（评论/回复/点赞）
    BOTH = "both"                # 两者皆可（默认）

class AccountStatus(str, Enum):
    ACTIVE = "active"                    # 正常可用
    EXPIRED = "expired"                  # Cookie过期
    INVALID = "invalid"                  # Cookie无效
    NEEDS_RELOGIN = "needs_relogin"      # 需要重新登录
    COOLDOWN = "cooldown"                # 冷却中（连续失败3次）
    DISABLED = "disabled"                # 已禁用
```

### 4.4 服务层核心方法

```python
class UnifiedAccountService:
    """统一账号管理服务"""

    MAX_FAILURES = 3              # 连续失败3次进入冷却
    COOLDOWN_SECONDS = 1800       # 冷却30分钟

    # ==================== 核心方法 ====================

    async def ensure_table(self):
        """确保 unified_accounts 表存在（幂等，仅首次执行DDL）"""

    async def add_account(self, user_id, platform, account_name, cookies,
                          role="both", capabilities=None, daily_limit=5,
                          account_group="", region="", label="",
                          owner_user_id=None) -> UnifiedAccount:
        """添加账号"""

    async def acquire_cookie(self, platform, role="both", user_id=1,
                             group=None, region=None) -> Optional[UnifiedAccount]:
        """从池中获取一个可用账号
        策略：
        1. 筛选：platform + role + status=active + 未冷却 + 配额未满
        2. 排序：health_score降序 → successes降序 → last_used_ts升序（最久未用优先）
        3. 选中后更新：last_used_ts + today_count + last_publish/interact_time
        """

    async def mark_success(self, account_id: int, role: str = "both"):
        """标记成功：successes+1, failures=0, cooldown=0, health+5"""

    async def mark_failure(self, account_id: int, reason: str = "", role: str = "both"):
        """标记失败：failures+1, health-5
        若 failures >= 3：进入冷却30分钟, health-20, status=cooldown"""

    async def mark_login_expired(self, account_id: int):
        """标记登录失效：status=needs_relogin, is_active=False, health=0"""

    # ==================== 查询方法 ====================

    async def get_account_by_id(self, account_id) -> Optional[UnifiedAccount]
    async def list_accounts(self, platform=None, role=None, user_id=None,
                            group=None, region=None, status=None) -> List[UnifiedAccount]
    async def _list_available_accounts(self, platform, role, user_id,
                                       group=None, region=None) -> List[UnifiedAccount]

    # ==================== 辅助 ====================

    @staticmethod
    def _get_engine():
        """获取异步数据库引擎（公共方法，遵循项目工程约定）"""
        from database.db_session import get_async_engine
        import config
        return get_async_engine(config.SAVE_DATA_OPTION)
```

**健康度算法**：

| 事件 | 健康度变化 | 其他变化 |
|------|-----------|----------|
| 成功 | +5（上限100） | failures=0, cooldown=0 |
| 失败 | -5（下限0） | failures+1 |
| 连续失败3次 | -20 | status=cooldown, cooldown_until=now+1800s |
| 登录失效 | =0 | status=needs_relogin, is_active=False |

| — | role = 'publisher' | 固定值 |
| — | capabilities = '["publish"]' | 固定值 |
| failures * 5 | health_score = 100.0 - (failures * 5.0) | 根据失败次数计算 |
| "group" | account_group | 字段重命名 |

| — | capabilities = '["comment","like"]' | 固定值 |
| health_score | health_score | 直传 |
| — | daily_limit = 5 | 默认值 |
