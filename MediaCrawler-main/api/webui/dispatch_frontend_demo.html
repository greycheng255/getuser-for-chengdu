二、前端页面展示

访问路径: 登录后进入侧边栏 账号与互动 → 客户分配调度,或直接访问 /customer-dispatch

页面功能:

  • 计划列表 Tab: 展示所有分配计划,支持「查看」「删除」,分页浏览
  • 新建计划: 表单填写计划名称/平台/筛选条件,动态添加账号并设置区间容量,「预览客户数」实时核算
  • 计划详情 Tab: 展示区间分配表、进度统计卡、账号取数操作区、分配记录表
  • 取下一批: 输入账号序号 + 批次大小,一键取数,自动应用去重与漏单补发规则

三、核心调度规则(前端页面规则说明区原文)

  • 优先发送本账号区间内的 pending 客户(编号连续推进)
  • 本区间发完后,自动补充其他账号漏单(sent 但未 replied)的客户,确保全覆盖
  • 已 replied 的客户会被所有账号自动跳过(去重)
