# 五功能自动化流水线整合方案

## 摘要

将"提示词库、视频参数配置、人工复核、发布调度管理、话术库"五个独立功能串联为完整自动化流水线：

```
[输入源] → 提示词库(沉淀/复用) → 视频参数配置 → 数字人视频生成
       → 人工复核(强制) → 发布调度管理(定时/错峰) → 话术库互动(自动触发)
```

核心改造：新增统一编排服务 `unified_pipeline.py`，并在人工复核"通过"和发布"完成"两个关键节点植入自动衔接回调，使原本割裂的五个功能形成闭环。

---

## 一、当前状态分析

### 1.1 五个功能模块现状

| 功能 | 后端服务 | API 路由 | 前端页面 | 衔接状态 |
|------|---------|---------|---------|---------|
| 提示词库 | `api/services/ai/prompt_library.py` | `/api/ai/prompt-library/*` | `PromptLibrary.tsx` | 仅沉淀，未作为输入源复用 |
| 视频参数配置 | `api/services/ai/video_generation_config.py` | `/api/ai/video-config/*` | `VideoGenConfig.tsx` | 已接入 `full-pipeline` |
| 人工复核 | `api/services/moderation/review_workflow.py` | `/api/moderation/review/*` | `ReviewQueue.tsx` | **未接入流水线**（被自动审核替代） |
| 发布调度管理 | `api/services/scheduling/publish_scheduler.py` | `/api/scheduling/*` | `PublishSchedule.tsx` | **未接入流水线**（当前立即发布） |
| 话术库 | `api/services/interactor/script_library.py` | （在 interact.py） | `ScriptLibrary.tsx` | **未接入流水线**（仅 CRUD） |

### 1.2 现有 `run_full_pipeline` 的问题

当前 `api/services/ai/prompt_storyboard_pipeline.py:333` 的 `run_full_pipeline` 流程：

```
热点视频 → AI拆解 → 提示词沉淀 → 视频生成 → 自动审核 → 立即自动发布
```

**三个关键断点**：
1. ❌ 跳过人工复核（直接自动审核）
2. ❌ 跳过发布调度（立即发布而非定时错峰）
3. ❌ 跳过话术库互动（发布后无互动引导）

### 1.3 关键接口清单（已确认存在）

- **提示词库**: `library.get(prompt_id)`, `library.save_prompt()`, `library.find_similar()`
- **视频配置**: `svc.get_config(config_id)` → `VideoGenConfig`
- **人工复核**: `svc.create_review_task()`, `svc.submit_review()`（状态 pending→approved/rejected）
- **发布调度**: `scheduler.schedule_task(ScheduledTask)` → 定时任务ID
- **多平台发布**: `publisher.publish_to_multiple_platforms(PublishTask)`
- **话术库**: `library.pick_random(platform, scene)` → Script
- **互动调度**: `interaction_scheduler.schedule_interaction()`（`api/services/interactor/interaction_scheduler.py:210`）
- **视频生成**: `ExplainerVideoClient.generate_video()`

## 二、方案设计

### 2.1 完整流水线流程

```
┌─────────────────────────────────────────────────────────────┐
│  输入源（三选一）                                              │
│  ① 热点视频URL  ② 提示词库prompt_id  ③ 手动文案              │
└───────────────────────┬─────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────────────┐
│  Step 1: 提示词库                                             │
│  - URL输入 → extract_from_hotspot() 拆解+沉淀                 │
│  - prompt_id输入 → library.get() 复用                         │
│  - 手动文案 → 直接作为prompt                                  │
│  产出: prompt_text, prompt_id, storyboard                    │
└───────────────────────┬─────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────────────┐
│  Step 2: 视频参数配置                                          │
│  - 根据 video_config_id 加载 VideoGenConfig                   │
│  - 无则用默认配置                                              │
│  产出: video_config                                           │
└───────────────────────┬─────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────────────┐
│  Step 3: 数字人口播视频生成                                    │
│  - 调用 _generate_video(prompt, video_config)                │
│  - 持久化到视频资产库                                          │
│  产出: video_url, asset_id                                    │
└───────────────────────┬─────────────────────────────────────┘
                        ↓
┌─────────────────────────────────────────────────────────────┐
│  Step 4: 人工复核（强制）                                      │
│  - 调用 review_workflow.create_review_task()                 │
│  - 流水线状态置为 "reviewing"，暂停等待                        │
│  产出: review_id (status=pending)                             │
└───────────────────────┬─────────────────────────────────────┘
                        ↓ 人工 approved
┌─────────────────────────────────────────────────────────────┐
│  Step 5: 发布调度管理（复核通过回调触发）                       │
│  - 调用 publish_scheduler.schedule_task()                    │
│  - 推荐错峰时间 recommend_publish_time()                      │
│  - 调度器到期执行 multi_publisher.publish_to_multiple_platforms│
│  产出: schedule_task_id, scheduled_at                         │
└───────────────────────┬─────────────────────────────────────┘
                        ↓ 发布完成
┌─────────────────────────────────────────────────────────────┐
│  Step 6: 话术库互动（发布完成回调触发）                         │
│  - 调用 script_library.pick_random(platform, comment_reply)  │
│  - 调用 interaction_scheduler.schedule_interaction()         │
│  - 自动发布首条评论/互动引导                                   │
│  产出: interaction_task_id                                    │
└───────────────────────┬─────────────────────────────────────┘
                        ↓
                   流水线完成 ✅
```

### 2.2 关键决策（用户已确认）

1. **强制人工复核**：视频生成后一律进入待复核队列，不自动发布
2. **自动触发互动**：发布成功后自动从话术库选取话术调用互动调度器

### 2.3 数据流转设计

新增 `pipeline_tasks` 表追踪整个流水线状态：

```sql
CREATE TABLE pipeline_tasks (
  pipeline_id VARCHAR(64) PRIMARY KEY,        -- 流水线任务ID
  status VARCHAR(32) DEFAULT 'pending',       -- pending/extracting/generating/reviewing/scheduling/published/interacting/completed/failed
  source_type VARCHAR(32),                    -- hotspot_url/prompt_id/manual_text
  source_value TEXT,                          -- 原始输入
  prompt_id VARCHAR(64),                      -- Step1 产出
  video_config_id VARCHAR(64),                -- Step2 输入
  video_url TEXT,                             -- Step3 产出
  asset_id VARCHAR(64),                       -- 视频资产ID
  review_id VARCHAR(64),                      -- Step4 产出
  schedule_task_id VARCHAR(64),               -- Step5 产出
  publish_results TEXT,                       -- 发布结果JSON
  interaction_task_id VARCHAR(64),            -- Step6 产出
  publish_platforms TEXT,                     -- 目标平台JSON
  owner_user_id INTEGER,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);
```

## 三、具体改造点

### 3.1 新增：统一编排服务 `api/services/ai/unified_pipeline.py`

**职责**：串联六个步骤，维护流水线状态，提供查询接口。

```python
class UnifiedPipeline:
    """五功能统一编排流水线"""

    async def run_unified_pipeline(
        self,
        source_type: str,           # hotspot_url / prompt_id / manual_text
        source_value: str,          # URL / prompt_id / 文案
        video_config_id: str = "",  # 视频参数配置ID
        publish_platforms: List[str] = None,  # 目标平台
        owner_user_id: int = None,
    ) -> Dict[str, Any]:
        """启动流水线，返回 pipeline_id"""
        # 1. 创建 pipeline_tasks 记录，状态=pending
        # 2. Step1: 提取/复用 prompt
        # 3. Step2: 加载 video_config
        # 4. Step3: 生成视频
        # 5. Step4: 创建人工复核任务，状态=reviewing，暂停
        # 6. 返回 pipeline_id, review_id（后续由复核回调驱动）

    async def _step1_prompt(self, source_type, source_value, ...) -> Dict
    async def _step2_config(self, video_config_id) -> VideoGenConfig
    async def _step3_generate(self, prompt, video_config) -> str  # video_url
    async def _step4_create_review(self, pipeline_id, video_url, prompt, ...) -> str  # review_id

    async def proceed_after_review(self, review_id: str) -> Dict:
        """复核通过后由 review_workflow 回调，执行 Step5+6"""
        # 1. 查 pipeline_tasks 获取 video_url/platforms
        # 2. Step5: 创建定时发布任务
        # 3. 发布调度器到期执行后，回调 proceed_after_publish

    async def proceed_after_publish(self, pipeline_id: str, publish_results: List) -> Dict:
        """发布完成后由 publish_scheduler 回调，执行 Step6"""
        # 1. Step6: 选取话术 + 调度互动

    async def get_pipeline_status(self, pipeline_id: str) -> Dict
    async def list_pipelines(self, limit=20) -> List[Dict]
```

### 3.2 改造：人工复核服务 `review_workflow.py`

**改造点**：`submit_review()` 方法，当 decision=approved 时自动回调流水线。

```python
async def submit_review(self, review_id, reviewer_id, decision, notes, tags) -> bool:
    # ... 原有更新逻辑 ...
    if decision == ReviewStatus.APPROVED.value:
        # 检查是否属于流水线任务（content_id 格式: pipeline_xxx）
        content_id = ...  # 从 review_task 读取
        if content_id.startswith("pipeline_"):
            try:
                from api.services.ai.unified_pipeline import get_unified_pipeline
                await get_unified_pipeline().proceed_after_review(review_id)
```

### 3.5 新增：统一API路由（在 `stage1_extensions.py` 末尾追加）

```python
# ============ 统一流水线 ============
unified_pipeline_router = APIRouter(prefix="/pipeline", tags=["unified-pipeline"])

class RunPipelineRequest(BaseModel):
    source_type: str  # hotspot_url / prompt_id / manual_text
    source_value: str
    video_config_id: str = ""
    publish_platforms: List[str] = ["douyin"]
    owner_user_id: Optional[int] = None

@unified_pipeline_router.post("/run")
async def run_pipeline(req: RunPipelineRequest):
    """启动五功能统一流水线"""
    pipeline = get_unified_pipeline()
    result = await pipeline.run_unified_pipeline(
        source_type=req.source_type,
        source_value=req.source_value,
        video_config_id=req.video_config_id,
        publish_platforms=req.publish_platforms,
        owner_user_id=req.owner_user_id,
    )
    return {"code": 0 if result.get("success") else 5000, "data": result}

@unified_pipeline_router.get("/{pipeline_id}")
async def get_pipeline_status(pipeline_id: str):
    pipeline = get_unified_pipeline()
    return {"code": 0, "data": await pipeline.get_pipeline_status(pipeline_id)}

@unified_pipeline_router.get("")
async def list_pipelines(limit: int = Query(20, ge=1, le=100)):
    pipeline = get_unified_pipeline()
    return {"code": 0, "data": {"items": await pipeline.list_pipelines(limit)}}
```

## 五、假设与决策

### 假设
1. 现有 `ExplainerVideoClient.generate_video()` 可正常生成视频（非本次改造范围）
2. `interaction_scheduler.schedule_interaction()` 接口可正常调度互动任务
3. 发布调度器 `PublishScheduler` 已有后台轮询机制执行到期任务
4. 用户已配置目标平台的发布账号（cookie等）

### 决策
1. **不破坏现有 `run_full_pipeline`**：保留原方法，新增 `UnifiedPipeline` 独立服务，避免影响已有调用
2. **流水线状态持久化**：使用 `pipeline_tasks` 表，避免内存丢失
3. **回调机制采用直接函数调用**：review_workflow → unified_pipeline → publish_scheduler，避免引入消息队列复杂度
4. **前端新增独立看板页**：避免改动现有页面过大，同时提供全景视图
5. **`source_pipeline_id` 可选**：手动创建的发布任务不影响，仅流水线任务带此字段
