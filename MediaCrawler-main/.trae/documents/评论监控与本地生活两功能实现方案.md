# 评论监控 + 本地生活 两个新功能实现方案

## Context（背景）

用户提出两个新业务需求：
1. **评论监控**：监控热门同行账号ID或爆款视频下的评论，用于评论采集分析、筛选意向客户、自动回复评论（多平台：抖音/小红书/快手/B站/微博）
2. **本地生活**：获取火锅店等商家的电话/联系方式/营业信息（抖音POI + 高德地图API）

现状：项目已有各平台评论爬虫能力（`media_platform/{plat}/client.py`）、`InteractionMonitor` 监控框架、`CustomerLead` 线索模型，但缺少统一的评论监控任务管理、AI 意向识别、本地商家信息采集能力。本方案在现有能力上扩展，不重复造轮子。

### 1.2 平台评论抓取抽象层

**新建文件**：`api/services/comment_monitor/platform_comment_fetcher.py`

```python
@dataclass
class UnifiedComment:
    platform: str; post_id: str; post_url: str
    comment_id: str; comment_text: str
    author_id: str; author_nickname: str; author_sec_uid: str
    parent_comment_id: str; like_count: int; created_ts: int

@dataclass
class CommentFetchResult:
    comments: List[UnifiedComment]; has_more: bool; next_cursor: Any

class PlatformCommentFetcher(ABC):
    PLATFORM: str
    @abstractmethod
    async def fetch_comments(self, target_id, cursor=None, max_count=100) -> CommentFetchResult: ...
    @abstractmethod
    async def fetch_user_posts(self, sec_user_id) -> List[Dict]: ...

class CommentFetcherFactory:
    @classmethod
    def create(cls, platform, cookies, user_id) -> PlatformCommentFetcher: ...
```

**Phase 1 实现**：`DouyinCommentFetcher`（复用 `media_platform/douyin/client.py` 的 `get_aweme_all_comments` + `get_all_user_aweme_posts`）

**Phase 2 预留**：`XhsCommentFetcher` / `KsCommentFetcher` / `BiliCommentFetcher` / `WbCommentFetcher`（先抛 NotImplementedError，架构可扩展）

**cookie/浏览器获取**：复用 `account_service.acquire_cookie(platform, user_id)` + 轻量 playwright 启动（参考 `interaction_monitor._fetch_comments` 已验证模式：`InteractorFactory.create(platform, cookies=...)` → `_init_browser` → 拿 `interactor.page` 喂给 client）。

### 1.4 服务层

**新建文件**：`api/services/comment_monitor/comment_monitor_service.py`

```python
class CommentMonitorService:
    async def ensure_table(self): ...
    # 任务CRUD
    async def create_task(self, *, platform, monitor_type, target_id, ...): ...
    async def list_tasks(self, *, owner_user_id, platform=None, status=None, page=1, page_size=20): ...
    async def get_task / update_task / delete_task: ...
    # 启停（内存协程管理）
    async def start_task(self, task_id, owner_user_id): ...  # asyncio.create_task(_run_task_with_watchdog)
    async def stop_task(self, task_id, owner_user_id): ...
    # 监控主循环（仿 interaction_monitor._run_with_watchdog）
    async def _run_task_with_watchdog(self, task_id): ...
    async def _check_once(self, task_id): ...
    async def _check_account_comments(self, task) -> List[UnifiedComment]: ...  # 先fetch_user_posts再逐个fetch_comments
    async def _check_video_comments(self, task) -> List[UnifiedComment]: ...
    async def _process_new_comments(self, task, comments): ...  # 落库+关键词匹配+AI识别+自动回复
    # 启动恢复
    async def start_all_persistent_tasks(self): ...  # main.py startup调用，恢复status=running的任务
    # 评论记录查询
    async def list_records(self, task_id, page, page_size): ...
    async def get_task_stats(self, task_id): ...

def get_comment_monitor_service() -> CommentMonitorService: ...  # 单例
```

**去重策略**：内存 `set` 维护近 1000 条已处理 comment_id，超限回写 DB，`(task_id, comment_id)` 唯一索引兜底。

**风控**：`_check_once` 间隔加 `random.uniform(0, 60)` 抖动；自动回复单轮上限 5 条；检测到平台风控信号自动暂停 1 小时。

## 五、验证方法

### 评论监控
1. 启动 API，日志可见 `comment_monitor_task` / `comment_monitor_record` 表创建
2. `POST /api/comment-monitor/tasks` 创建抖音视频监控任务（target_id=某aweme_id）
3. `POST /tasks/{id}/start` 启动，等一个 check_interval 后 `GET /tasks/{id}/records` 有评论
4. 查 `customer_lead` 表有评分≥50 的线索
5. 开启 auto_reply 后原视频下有机器人评论
6. 前端 `/comment-monitor` 页面可创建/启停/查看记录

### 本地生活
1. `GET /api/local-life/config` 返回 configured:true
2. `GET /api/local-life/search?keyword=火锅&city=成都` 返回高德POI列表含电话/地址/营业时间
3. `POST /api/local-life/businesses/save` 保存后 DB `local_business` 有行
4. `GET /api/local-life/businesses/export?fmt=xlsx` 下载xlsx列完整
5. 前端 `/local-life` 页面可搜索/保存/列表/导出
