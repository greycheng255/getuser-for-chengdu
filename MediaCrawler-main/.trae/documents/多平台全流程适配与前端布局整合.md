# 多平台全流程适配与前端布局整合

## Context（背景）

当前系统的"一键拆解全流程"和"发布到自己账号"两条链路都是 X 平台专属：

1. **后端 `auto_pipeline.py`**（L131-144）：`_get_post(post_id)` 从 `XTwitterPost` 表读数据，`run_pipeline` 内部固定走 `_do_publish_to_x`（GraphQL）。其他平台无法复用。
2. **前端 XWorkbench** 有 7 个 Tab，其中「监控设置/评论模板/通知渠道/回复规则」4 个 Tab 与独立的 `InteractionConfig` 页面功能重叠，分散在 3 处（XWorkbench / BotAccounts / InteractionConfig），页面拥挤。
3. **BreakdownModal** 的"视频拆解"按钮调 `publishToX`（X 专用），无法发布到其他平台。

目标：
- 新建 platform-agnostic 的 `auto_pipeline_service.py`，让"热点→拆解→文案→发布→互动→监控"支持多平台，X 走 GraphQL、其他平台走 `MultiPlatformPublisher`。保留旧 `auto_pipeline.py` 不动。
- XWorkbench 从 7 Tab 瘦身到 3 Tab（热点内容/已发评论/效果分析），4 个配置 Tab 迁入 BotAccounts。
- BreakdownModal 加「多平台一键发布」入口。

## 后端改动

### 新建 3 个文件

#### 1. `api/services/auto_pipeline_task_store.py`
参照 `api/services/publisher/publish_records_store.py` 模式（用 SQLAlchemy `Table` + `MetaData`，不新增 ORM model，避免 alembic 迁移）。新建 `auto_pipeline_tasks` 表（platform-agnostic）：
- `task_id VARCHAR(64) PK`, `platform VARCHAR(32)`, `source_post_id VARCHAR(128)`, `source_post_url TEXT`
- `status`, `current_step`, `step_detail`, `breakdown_text`, `video_url`, `selected_content`
- `published_post_id`, `published_post_url`, `account_id`, `interaction_triggered`
- `error_msg`, `options JSONB`, `owner_user_id`, `add_ts`, `update_ts`

封装 `ensure_table / create_task / update_task / get_task / list_tasks / cancel_task`。

#### 2. `api/services/auto_pipeline_service.py`（核心）
**平台能力矩阵**（决定每平台走哪条发布路径）：
```python
PLATFORM_CAPABILITIES = {
    "x":           {"publisher": "x_graphql", "interactor": "x_twitter",
                    "cookie_source": "env_pool", "monitor": "x_native", "max_content": 280},
    "douyin":      {"publisher": "multi_publisher", "interactor": "douyin",
                    "cookie_source": "account_service", "monitor": None, "max_content": 2000},
    "xiaohongshu": {"publisher": "multi_publisher", "interactor": "xiaohongshu",
                    "cookie_source": "account_service", "monitor": None, "max_content": 1000},
    "bilibili":    {"publisher": "multi_publisher", "interactor": "bilibili",
                    "cookie_source": "account_service", "monitor": None, "max_content": 2000},
    "weibo":       {"publisher": "multi_publisher", "interactor": "weibo",
                    "cookie_source": "account_service", "monitor": None, "max_content": 2000},
    "zhihu":       {"publisher": "multi_publisher", "interactor": "zhihu",
                    "cookie_source": "account_service", "monitor": None, "max_content": 10000},
}
SUPPORTED_PLATFORMS = list(PLATFORM_CAPABILITIES.keys())
```

**核心函数**：
- `start_pipeline(platform, hotspot_item, options, server_base_url) -> task`：创建任务 + `asyncio.create_task` 异步执行
- `run_pipeline(task_id, server_base_url)`：8 步流水线
  - Step 1 视频拆解：复用 `ai_agent_client.generate_video_breakdown(post)`（platform-agnostic）
  - Step 2 生成解说视频：复用 `ai_agent_client`（可 skip）
  - Step 3 生成发布文案：X 走 `generate_x_post_content`，其他走新 `generate_platform_post_content`
  - Step 4 AI 选文案：复用旧 `_ai_select_best_content` 逻辑
  - Step 5 填入 video_url
  - Step 6 **平台路由发布**（关键）：
    - X：从 `cookie_pool_manager._parse_pool_from_env()` + `X_TWITTER_COOKIES` 取 cookie，调 `_do_publish_to_x`（与旧 auto_pipeline.py 一致）
    - 其他：调 `MultiPlatformPublisher.publish_to_single_platform`（自带 account_service cookie 池 + 重试 + 配额）
  - Step 7 触发互动（可选）：`MultiInteractor.interact_across_platforms` 给新帖点赞造势
  - Step 8 启动监控（仅 X）：写入 `XTwitterMonitoredPost`，确保 `comment_reply_monitor` 运行

**关键差异点 vs 旧 `auto_pipeline.py`**：
- 不依赖 `XTwitterPost` 表：`hotspot_item` 由前端传入（platform-agnostic，含 post_id/post_url/content/video_url/username）
- Step 6 路由分发：旧版固定调 `_do_publish_to_x`，新版按 `PLATFORM_CAPABILITIES` 路由
- 持久化用新 `auto_pipeline_tasks` 表（platform-agnostic），不污染 `x_twitter_auto_pipeline_task` 表

#### 3. `api/routers/auto_pipeline.py`
```python
router = APIRouter(prefix="/auto_pipeline", tags=["auto-pipeline"],
                   dependencies=[Depends(get_current_user)])

class RunPipelineRequest(BaseModel):
    platform: str  # x/douyin/xiaohongshu/bilibili/weibo/zhihu
    hotspot_item: Dict[str, Any]  # post_id/post_url/content/video_url/username
    skip_video: bool = False
    auto_monitor: bool = True
    trigger_interaction: bool = False

@router.post("/run")        # 单条热点一键拆解+发布
@router.get("/platforms")   # 列出支持全流程的平台（含能力标注）
@router.get("/{task_id}")   # 查询任务状态
@router.get("")             # 列出任务
@router.post("/{task_id}/cancel")
@router.websocket("/ws/{task_id}")  # 实时进度（参照 x_workbench_auto_pipeline.py 的 ws 实现）
```
